# Mythos (pacote do plugin)

Pacote instalável do Plugin Mythos para ChatGPT e Codex.

- `plugin.json`: manifesto portátil (Agent Plugins 1.0.0) com a apresentação da OpenAI em `extensions.com.openai`.
- `mcp.json`: servidor MCP remoto `https://plugin-mythos.vercel.app/mcp` (streamable HTTP, sem autenticação).
- `.codex-plugin/plugin.json` e `.mcp.json`: formato de compatibilidade.
- `skills/`: `mythos-slides`, `mythos-site`, `mythos-interactive` e `setup` (onboarding).

Instruções completas no [README do repositório](../../README.md).
